# Episode 1 footage: where each shot is

For `softbank-975.md`. Download each file, rename it exactly as the **file**
column says (the `-at-N` part is where the shot starts, in seconds), and
attach it to the GitHub Release `footage-softbank-975`; then run the
`episode` workflow with slug `softbank-975`. A shot left out renders as a
slate, so the film can go out with any of them missing.

Checked 1 Oct 2026, and the six rows added on 3 Oct 2026 checked that day
from the build sandbox: every link below answered, its licence was read on
the item itself or the rule that covers it, each media URL answered a
one-byte range request with the stated type, and a poster frame or
thumbnail was looked at. No video was downloaded, so where an in-point
rests on thumbnails the Notes say so. "Public domain" here means a work of
the US government (17 U.S.C. 105) or an item marked CC0 or Public Domain
Mark by its archive.

## Credits and the file names

Beside the files, attach `credits.txt` to the same Release: one line per
file, `id: source, licence`, in the order above (for example
`son-stargate: White House livestream, 21 Jan 2025, public domain`). The
film's description carries them under "Footage:", and the render names
every file in use that has no line. Names are matched case-blind, with
spaces and underscores read as hyphens, so `Son Stargate-at-402.5.MP4`
still lands; a file whose `-at-` number is past its own end is refused for
a clip and played from its start for footage, and the render says so.
Shoot the tote bag landscape: a portrait picture in the wide film sits
between two black bars rather than filling the frame.
