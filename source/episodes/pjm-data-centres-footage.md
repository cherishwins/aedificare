# Episode 2 footage: where each shot is

For `pjm-data-centres.md`. Download each file, rename it exactly as the
**file** column says (the `-at-N` part is where the shot starts, in
seconds), and attach it to the GitHub Release `footage-pjm-data-centres`;
then run the `episode` workflow with slug `pjm-data-centres`. A shot left
out renders as a slate, so the film can go out with any of them missing.
The renderer reads one file per shot, so where a row offers a second or
third item it is a swap under the same name, not an extra beat.

Checked 3 Oct 2026 from the build sandbox: every link below answered, its
licence was read on the item itself or the rule that covers it, each media
URL answered a one-byte range request with the stated type, and a poster
frame or thumbnail was looked at. No video was downloaded, so where an
in-point rests on thumbnails the Notes say so. "Public domain" here means
a work of the US government (17 U.S.C. 105) or an item marked CC0 or
Public Domain Mark by its archive.

## Credits and the file names

Beside the files, attach `credits.txt` to the same Release: one line per
file, `id: source, licence`, in the order above (for example
`wh-pledge: White House livestream, 4 Mar 2026, public domain`). The
film's description carries them under "Footage:", and the render names
every file in use that has no line. Names are matched case-blind, with
spaces and underscores read as hyphens, so `Wh Pledge-at-100.MP4`
still lands; a file whose `-at-` number is past its own end is refused for
a clip and played from its start for footage, and the render says so.
