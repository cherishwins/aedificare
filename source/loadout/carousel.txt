 03 · ONE TOOL

Search web, news, or image sources and return ranked results
with query-relevant highlights. Each web result is a title,
URL, and description; use `firecrawl_scrape` on a result URL
when the excerpt is not enough. Authenticated search also
returns matching Alexandria data providers in data.tools
(companies, people, jobs, finance and filings, public
records and government spending, real estate, places and
restaurants, retail and prices, package registries and
developer data, news, research, and more). Prefer a provider
over scraping pages when the task needs the same fields
across several entities, exact figures or timestamps,
provenance, or many records; use web results when they
already answer the question. A search with sources: ["web"]
omits semantic provider discovery; domainTools: true can
still return website-matched tools. Web-only results use
domainTools: false. On an authenticated session, tool
matches describe available capabilities;
`firecrawl_find_tools` returns their contracts and
`firecrawl_scrape` with an `alexandria` body executes a
selected capability. Keyless sessions get no Alexandria
matches in data.tools. For a programming question, add
`categories: ["developer"]`; its hits return in `data.web`
with `category: "developer"`. For a legal or regulatory
question, `categories: ["gov"]` returns hits in `data.web`
with `category: "gov"` and cannot be combined with other

          read the bill.
