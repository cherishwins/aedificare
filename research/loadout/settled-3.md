# Settled, lane 3: MCP claims (LOADOUT, Edition 07, 10 Oct 2026)

Settled 2026-11-01 by the main thread from `research/loadout/lane-3.md` and `research/loadout/skeptic-3.md`. The two disagree on 3.1, 3.2 and 3.3, and the main thread opened each of those primaries itself. On 3.4 and 3.5 they agree, verdict and wording, and those rows rest on the two passes; the main thread did not reopen them.

How the pages were read. The MCP changelog and transports page were fetched as markdown (`modelcontextprotocol.io/specification/2026-07-28/...md`) and the MCP blog post as HTML, and read whole. Cloudflare's README was read raw at commit d5d326e, the last change to README.md before the edition, and the commit's date was read from the repository's own history (a blobless clone, no checkout, nothing installed or run): d5d326e is 2026-10-08T18:45:30-07:00, that is 9 Oct 01:45 UTC, and the next README commit, 8158532, is 2026-10-19. So the d5d326e text is the README as it stood all of 10 Oct. The servers README was read raw from `main`; The Hacker News article as HTML.

Walls met, none worked round. github.com and api.github.com answered 403 to this sandbox for the advisory pages, the repository's advisory list and Cloudflare's commit API ("GitHub access to this repository is not enabled for this session"); no repository was attached to get past it. The six GitHub advisories were read instead from OSV (`api.osv.dev/v1/vulns/<GHSA id>`), which republishes the GitHub Advisory Database record under the same id with its aliases, published time, summary and affected ranges. OSV is a mirror of the primary, not the primary; the URL column says so. The repository's own advisory list, which the skeptic read on its two pages, was not reopened, so the count of advisories "up to 10 Oct" (none between 26 Feb and 25 Oct 2026) rests on the skeptic.

## For the owner

- **"Two Anthropic reference servers" (print 21).** A description of who runs the servers, so it is left as written. The servers README says both "maintained by the MCP steering group" (its opening note) and "Managed by Anthropic, but built together with the community" (its closing line), and The Hacker News calls mcp-server-git "maintained by Anthropic". Whether the page says "Anthropic", "the MCP project's" or neither is the owner's call.
- **Tier A on the filesystem and git rows** (map, lines 287 and 291). Tier A is "we ran or observed it"; the CVEs are read from advisories, not run here. The owner may want tier B on those two notes, or the tier read as applying to the token count beside them.
- **"Stateless" and the servers measured.** The map says every server booted "negotiated protocol 2025-11-25" (line 230), the revision before the session removal. The 2026-07-28 spec defines a fallback for such servers, so a reader connecting today will meet servers that still keep sessions. True as printed; whether rung 3 should say so is the owner's.
- **Cloudflare's tool count moved three days before the edition**: `whoami` was added 7 Oct 2026 (UTC) and the README's token table still counted three on 10 Oct. The amended wording drops the count rather than choose between the vendor's two tables.
- **Changed since 10 Oct, not used in any verdict.** New advisories on the two reference servers (the skeptic's read of the repository's list, not reopened here): on 25 Oct three for server-filesystem (GHSA-4gxg-m5jx-9j57, GHSA-53mr-w429-c597, GHSA-hhwq-wxfx-cj7g) and GHSA-7rgq-gccq-qphx (a validatePath traversal, no package named on the listing), and on 28 Oct GHSA-w766-5x43-whvw for mcp-server-git. A reprint recounts. Cloudflare's README has commits from 19 to 28 Oct; its token and tools tables read the same on `main` today. The MCP spec's versioning page lets a current revision take backwards-compatible changes; no change to its major changes was found.
