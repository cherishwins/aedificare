# Research runs

One folder per run, `research/<slug>/`, written by the crew the research
skill describes (`.claude/skills/research/SKILL.md`):

- `lane-<n>.md`: a researcher's verdicts for one lane, with the primary's
  own words, its URL and the day it was read.
- `skeptic-<n>.md`: the skeptic's pass over that lane: upheld, overturned
  or amended, with its evidence.
- `VERDICTS.md`: the settled table an edition is written from.
- `COST.md`: what the run cost and how many verdicts the skeptics
  overturned.

These are working evidence, kept so a later session can see why a page
says what it says. Nothing here ships with the site (`.vercelignore`).
